# 法律数据与题库：可获取性实测报告

> 本文件记录**实测**结果，不是推测。所有结论都对应 `scripts/fetch_banks.py` 的一次真实运行，
> 落盘文件、sha256、条数均可复现。
> 实测时间：2026-10-14　执行环境：本项目 `.venv`（Python 3.13）

---

## 一、一句话结论

**题库可以自行下载，且已经下载完成。** 当前已抓取 **5 个源 / 111,280 条记录 / 约 176 MB**，
其中 **3 个源许可明确可商用**。

但必须同时说清楚两件事：

1. **最大的一份（DISC-Law-SFT，10.3 万条）是"法律职业语料"，不是"大学生生活常识语料"**——
   它引用的法律里，证券法、海商法、票据法、信托法、破产法占了很大比重，与校园生活场景不匹配。
   它的价值在于**扩展新场景时的素材库和表述参考**，不等于可以直接当题库用。
2. **真正像"法考选择题"的 JEC-QA（999 题）许可恰恰是禁止商用的**。这与之前的结论一致，
   没有因为换了下载渠道而改变。

## 三、官方站（`flk.npc.gov.cn`）直连实测：不可用

`数据网址.md` 指向的国家法律法规数据库，**在本环境无法直连抓取**。实测：

| 请求 | 结果 |
|---|---|
| `GET https://flk.npc.gov.cn/` | 200，返回 SPA 空壳（552 字节 HTML） |
| `GET https://flk.npc.gov.cn/api/` | 200，**同样返回 SPA 空壳**，不是 JSON |
| `GET https://flk.npc.gov.cn/api/?type=flfg&page=1&size=3` | 200，仍是 SPA 空壳 |
| `GET https://flk.npc.gov.cn/api/list?page=1&size=3` | 200，仍是 SPA 空壳 |
| `POST https://flk.npc.gov.cn/api/detail` | **405 Not Allowed** |

即：前端已改为单页应用，公开文档里的旧版 `/api/` 接口在当前站点上**不再返回数据**。

**替代方案（均已实测可用）：**

| 替代 | 说明 |
|---|---|
| `twang2218/law-datasets`（MIT） | 从 flk 抓取的 22,552 部法律法规 JSON，截至 2023-09 |
| `qisehong/china-law-db` | 持续同步工具，Markdown + YAML，支持增量 |
| **项目现有 `data/laws.db`** | 378 部法律 / 23,995 条，来自 china-law-mcp（MIT），**运行时已够用** |

> 结论：法条这一侧**不缺数据**，现有 `laws.db` 已覆盖主要法律；若要补新法，
> 走上述镜像仓库，不必依赖官方站直连。

## 五、许可红线（发布纪律）

抓取 ≠ 可发布。本项目按 permit 分三层：

| 层 | 目录 | 可否随产品分发 | 说明 |
|---|---|---|---|
| **A. 发布层** | `data/questions/` | ✅ 可以 | 自建题库，每条须过 `validate_bank.py` 七道门禁 |
| **B. 语料层** | `data/external/banks/normalized/` | ⚠️ 仅 Apache-2.0 的来源可用 | 作参考、作素材，须标注来源 |
| **C. 隔离层** | `data/external/banks/raw/` | ❌ 禁止 | 受限源原始文件，**永不进 git** |

`data/external/` 已在 `.gitignore` 中，**受限数据不会进公开仓库**（`HY-Kai741/1`）。

**三条硬纪律：**

1. 许可未确认的源（LegalQA）→ 只进 C 层，不得进 A 层，不得随产品分发；
2. JEC-QA 系（含 AGIEval 转封版）→ 仅可作内部难度标定与自测基准，**禁止对外分发题目原文**；
3. 参考题型结构、标签体系、难度分布是允许的，**逐题复制原文不允许**——
   进入 A 层必须重新命题并逐条回库核验法条。

## 七、复现命令

```bash
# 查看源清单与许可
python scripts/fetch_banks.py --list

# 抓取全部许可可用的源
python scripts/fetch_banks.py --fetch all

# 抓取指定源（可限制条数）
python scripts/fetch_banks.py --fetch disc_law_sft_triplet_qa --limit 5000

# 放行许可受限的源（仅限内部参考）
python scripts/fetch_banks.py --fetch jecqa_ca legalqa --allow-restricted

# 查看已抓取统计
python scripts/fetch_banks.py --report
```

依赖：`pyarrow`（解析 parquet 格式的题库）。属**构建期依赖**，已单独放在 `requirements-build.txt`，
不进入运行时 `requirements.txt`（部署沙箱不必安装）。

落盘位置：

```
data/external/banks/
├── _registry.json          # 每个源的许可、sha256、条数、抓取时间（可追溯）
├── raw/                    # 原始下载文件（受限数据，不进 git）
└── normalized/             # 统一 jsonl（question / answer [ / choices / gold ]）
```
