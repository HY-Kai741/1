# plan-02 · 数据与知识库

| 项 | 值 |
|---|---|
| 对应 PRD | §9 数据与知识库、NFR-1/2/9 |
| 阶段 | Phase 1 |
| 优先级 | P0（阻塞 plan-04 / plan-05） |
| 依赖 | plan-01 |
| 规模档 | 中（数据清洗与入库需数天） |

---

## 1. 目标

建成三层知识资产：**法条层（已有）→ 知识点层（新建）→ 题库层（新建）**，且每一层都可溯源、可核验、许可清晰。

---

## 2. 三层资产结构

```
┌─────────────────────────────────────────┐
│ L3 题库层  questions                     │  题面/选项/答案/解析/知识点/难度/来源
├─────────────────────────────────────────┤
│ L2 知识点层  knowledge_points            │  部门法→章→节→知识点→关联法条
├─────────────────────────────────────────┤
│ L1 法条层  articles（已有）               │  378 部 / 23,995 条，逐字原文
└─────────────────────────────────────────┘
        ↑ 每层向上可溯源，向下可回验
```

**依赖方向必须是单向的**：题库引用知识点，知识点引用法条；法条不引用任何上层。

---

## 3. L1 法条层（沿用前身，做两件事）

| 任务 | 内容 |
|---|---|
| 校验 | 用国家法律法规数据库（`flk.npc.gov.cn`）抽样比对，确认条文现行有效 |
| 扩充 | 评估是否补入**司法解释**（前身明确缺失，导致"LPR 4 倍"类问题无法回答） |

**司法解释扩充是本计划的重点增量。** 前身已知边界：库内 378 部 / 23,995 条**不含司法解释、行政法规、地方性法规**。教学场景下缺失司法解释会明显影响质量（大量考点依赖司法解释）。

方案：从最高人民法院官网与法律法规数据库抓取司法解释，**单独建表**（不混入 `articles`），标注 `doc_type='司法解释'`，并在溯源时显式区分。

---

## 4. L2 知识点层（本产品自有资产）

### 4.1 结构

```json
{
  "id": "kp.civil.contract.validity",
  "title": "合同效力",
  "path": ["民法", "合同编", "合同的效力"],
  "level": 3,
  "summary": "一句话定义",
  "key_points": ["要件1", "要件2"],
  "related_articles": [
    {"law": "民法典", "article": 143, "role": "效力要件"},
    {"law": "民法典", "article": 153, "role": "无效情形"}
  ],
  "confusable_with": ["kp.civil.contract.effect", "kp.civil.contract.perform"],
  "difficulty": 3,
  "source": "自建（依据现行法条与主流教材体系）"
}
```

### 4.2 建设原则

1. **层级来源**：部门法 → 章 → 节 → 知识点，参照国家统一法律职业资格考试辅导用书目录体系；
2. **每个知识点必须挂靠至少 1 条法条**，挂不上的一律不建（防止凭空造概念）；
3. **必须标注易混点**（`confusable_with`），这是概念辨析功能的数据基础；
4. **标注难度 1–5**，用于学习路径与出题权重；
5. **自建资产，须标注版本与依据**，允许教师覆盖。

### 4.3 规模目标

| 阶段 | 知识点数 | 覆盖 |
|---|---|---|
| MVP | 150 | 8 大部门法的核心考点 |
| 完整 | 600+ | 覆盖法考大纲主要考点 |

## 5. L3 题库层

### 5.1 数据源

| 源 | 规模 | 题型 | 许可状态 |
|---|---|---|---|
| JEC-QA（`jecqa.thunlp.org`） | 26,365 题 | 单选 / 多选 / 不定项 | ❌ **禁止商用**（仅限学术研究） |
| CAIL / LAIC 赛题 | 历年 | 案例 / 判决 | ⚠️ 待核实 |
| 自建（由知识点 + 法条生成，经人工审定） | 目标 300+ | 概念辨析 / 案例 | ✅ 自有 |

**JEC-QA 许可已核实（2026-10-14）：明确禁止商业使用，仅限学术研究。**

证据（两处独立来源一致）：

1. 官方数据页 `jecqa.thunlp.org` 为**申请制**（"request the data"），不提供直接下载链接；
2. AGIEval 数据集（`ruixiangcui/AGIEval`，commit `b1187aa`）在引用说明中原文转述其条款：

> "Most of the questions in JEC-QA are obtained from real Chinese judicial exams and some practice tests compiled by commercial institutions. Therefore, this dataset is intended for **academic research only and commercial use is strictly prohibited**."

**处置结论：JEC-QA 不得进入发布题库。**

- 允许用途：**离线内部研究**（难度分布标定、题型与标签设计参考、内部自测基准）；
- 禁止用途：进入发布库、随产品分发给终端用户、用于商业产品；
- 派生产物（如"参照其题型自建的相似题"）**不得逐题复制原文**，须重新命题。

> 注意：本项目是**教育产品**，不等于条款中的"academic research"（学术研究），**不能援引该条款豁免**。判据是"是否对外分发"，而非"是否收费"。

**发布前仍须完成 CAIL / LAIC 等其余数据源的许可核实。许可不明的一律不入正式库，只可作离线研究参考。**

### 5.1.1 已实测抓取的数据源（2026-10-14 更新）

> 完整实测报告见 **`docs/DATA-BANKS.md`**。抓取工具：`scripts/fetch_banks.py`。
> 实测已落地 **5 个源 / 111,280 条 / 约 176 MB**，其中 **3 个源许可明确可商用**。

| 源 | 条数 | 许可 | 可商用 | 处置 |
|---|---:|---|---|---|
| DISC-Law-SFT-Pair-QA（复旦） | 79,692 | Apache-2.0 | ✅ | B 层语料（参考/素材） |
| DISC-Law-SFT-Triplet-QA（复旦） | 23,331 | Apache-2.0 | ✅ | B 层语料（**含法条依据，最好用**） |
| LegalQA（siatnlp） | 7,258 | 未声明 | ❌ | C 层隔离，仅内部参考 |
| JEC-QA-CA（AGIEval 整理） | 999 | 仅限学术研究 | ❌ | C 层隔离，仅内部难度标定 |
| laws-datasets 镜像 | 22,552 部 | MIT | ✅ | 法条扩展备选源 |

**两条必须记住的判断：**

1. **DISC-Law-SFT 是「法律职业语料」，不是「大学生常识语料」。** 引用统计显示证券法（4,925 次）、
   海商法（4,677 次）、票据法（2,496 次）、破产法（2,951 次）等商事非诉业务法律占比极高，
   超过一半内容与校园生活无关。**它有 10 万条，不等于题库问题解决了。** 其定位是
   「扩场景时的素材库与表述参考」，不是可直接使用的题库。
2. **真正形似法考选择题的 JEC-QA，许可恰恰禁止商用**——这一点没有因为换下载渠道而改变。

**官方站 `flk.npc.gov.cn` 直连实测结论：不可用。** 站点已改为单页应用，
旧版 `/api/` 接口全部返回 SPA 空壳，`POST /api/detail` 返回 405。
法条侧改用镜像仓库或现有 `data/laws.db`（378 部 / 23,995 条，已够运行时使用）。

**网络通道**：HuggingFace 走 `hf-mirror.com`；GitHub raw 走 `ghproxy.net` / `gh-proxy.com` /
`ghfast.top`。`fetch_banks.py` 已内置该降级链。

### 5.2 题目结构

```json
{
  "id": "q.civil.0001",
  "type": "single_choice",
  "stem": "题干",
  "options": [{"key": "A", "text": "..."}],
  "answer": ["C"],
  "explanation": "解析，引用法条",
  "citations": [{"law": "民法典", "article": 143}],
  "knowledge_points": ["kp.civil.contract.validity"],
  "difficulty": 3,
  "question_class": "KD",
  "source": {"name": "自建", "ref": "由 kp.civil.contract.validity 生成", "license": "自有"}
}
```

**关键字段说明：**
- `question_class`：KD（知识驱动）/ CA（案例分析），沿用 JEC-QA 分类；
- `citations`：解析中被引用的法条，**必须回库核验**；
- `source.license`：未填写或为"待核实"的题目**不得进入发布库**。

### 5.3 入库门禁

```
入库 = 结构合法 ∧ 答案非空 ∧ citations 全部回库核验通过 ∧ knowledge_points 存在 ∧ license 已确认
```

任一不满足 → **拒绝入库并记录原因**。门禁脚本输出可数的问题计数，通过标准是 0。

## 7. 验收标准

| 项 | 标准 | 可验证 |
|---|---|---|
| A1 | 三层资产全部可溯源 | 每层引用能逐级回跳至法条原文 |
| A2 | 知识点全部挂靠法条 | 无挂靠的知识点数 = 0 |
| A3 | 题库 citations 核验通过 | 失败数 = 0 |
| A4 | 许可核实完成 | `license` 为"待核实"的题目数 = 0（发布库内） |
| A5 | 知识点覆盖 8 大部门法 | 每部门法 ≥ 15 个知识点 |
| A6 | 司法解释可用 | 至少覆盖民法、刑法、诉讼法的核心解释 |

**通过标准：A3 与 A4 必须为 0；其余各项达标。**

## 8. 依赖与风险

| 风险 | 等级 | 应对 |
|---|---|---|
| JEC-QA 许可不允许商用 | 高 | **已确认禁止商用（2026-10-14）** → 题库主源改为自建；JEC-QA 仅作离线难度标定参考，不入发布库 |
| 拿来的真题法条已过时（法条修订导致答案失效） | 高 | 无论真题与否，题目答案须绑定法条版本；修订后自动标记待复核 |
| 自建题库人力投入超预期 | 中 | 分批交付：先 100 题覆盖 5 个高频场景，验证教学闭环后再扩量 |
| 知识点体系主观性 | 中 | 标注版本与依据来源；提供教师覆盖机制 |
| 司法解释抓取格式不一 | 中 | 建独立解析器 + 人工抽检 ≥ 5% |
| 数据规模超部署限制 | 中 | 现有 15 MB 已可跑；题库按需分包加载 |
