# 使用说明 · 大学生法律常识问答助手

> 给你——在校大学生的使用指南。不用懂法律术语，照着做就行。

---

## 一、这是个什么工具

它帮你回答三个问题：

1. **"我这种情况，法律是怎么规定的？"** —— 找到对应的法条，附上原文。
2. **"这条法条到底啥意思？"** —— 翻译成大白话。
3. **"那我下一步该怎么办？"** —— 从"先做什么"到"最后做什么"。

它**不是**什么：不是律师，不给法律意见，不能替你决定要不要打官司，也不能保证结果。

---

## 二、怎么用（30 秒上手）

1. 打开链接，看到对话框。
2. **直接用一两句话描述你的情况**。例如：
   > 退租时房东不退我押金，说我弄脏了墙，押金 2000 元。
3. 点发送。几秒内会得到一份六段式回答。
4. **如果我说"需要补充的信息"，就把那几点补上再发一次**——信息越全，结论越准。
5. 左侧的"常见情形"按钮可以快速套用例子，改一改再发。**这些按钮只对本次发送生效**——
   你换一个问题，系统就按新问题重新判断，不会还按上一次的领域回答。

---

## 三、它能处理哪些问题

| 领域 | 典型问题 |
|---|---|
| **租房纠纷** | 押金不退、提前退租、房东不修房、二房东、中介乱收费 |
| **兼职与劳动报酬** | 兼职欠薪、试用期不给钱、日结变成月结、被无故辞退 |
| **消费维权** | 网购退货被拒、七天无理由、假货三倍赔、外卖吃出异物 |
| **知识产权** | 论文/设计/照片被抄、被搬运到网上赚钱、没署你的名 |
| **借贷与校园贷** | 网贷利率过高、砍头息（到手比合同少）、还不上被暴力催收 |

其他领域（如交通事故、婚姻家庭）不在专项范围内。你仍然可以问，系统会从 378 部法律里尽力检索，
但会**明确标注"仅供参考"**，请务必自己核对原文。

---

## 四、怎么读这份回答（六段结构）

```text
一、结论          ← 先看这句，一句话概括你的情况
二、适用法条      ← 可能相关的条文，附"原文"（法律原文，不会改动一个字）
三、通俗解释      ← 上面每条法条的大白话翻译
四、行动建议      ← 【建议优先做】现在就能做的；【如果协商不成再做】升级路径
五、需要补充的信息 ← 我没说清的地方，补上它
六、免责声明      ← 固定提示：仅供参考，不构成法律意见
```

回答最下方还有一块 **"数据说明"**，会告诉你：这条法条出自哪、哪些字段缺失、有没有超出专项范围。
**请一定看一眼**，它决定了这份回答有多可靠。

**另外，结论下方会列出"本轮识别到的关键事实"**——也就是系统从你这句话里读出来的具体信息，
比如"涉及金额约 2000 元""已签（纸质/书面）租赁合同""有押金支付凭证"。

它的作用是让你一眼确认：**系统有没有理解对你的情况**。
如果你看到的事实清单和你说的是两回事，说明它理解偏了，换个说法再描述一次即可。
系统只会摘录你**真的说过**的内容，不会替你补事实。

## 五、五个真实示例（可以直接照抄改写）

**① 租房押金**
> 我大二，在学校附近租房，退租时房东不退我押金，说我把墙弄脏了，有微信转账记录和聊天记录，押金 2000 元，签了纸质合同。

**② 兼职欠薪**
> 我在奶茶店兼职，老板拖欠我两个月工资不给，说好 20 元一小时，有微信聊天记录和排班表。

**③ 网购退货**
> 我在淘宝买的东西和描述不符，收到才 3 天，想退货商家不给退，有订单截图和开箱视频，就是普通衣服。

**④ 校园贷**
> 我在一个网贷平台借了 5000，实际到手只有 4200，月息很高，现在还不上，他们打电话给我同学和父母。

**⑤ 论文抄袭**
> 我写的论文被同学抄了，他改了个标题就提交了，我这里有原稿和提交记录，查重相似度 90%。

## 六、几个你会关心的问题

**Q：法条是真的吗？会不会编造？**
不会。所有条文都从本地法律知识库（378 部法律 / 23,995 条现行条文）逐字取出，系统的评测会验证
每一条引用都真实存在、且与库内文字**逐字一致**。找不到依据时，它会直接说"未找到直接相关的法条"。

**Q：为什么不直接告诉我"我能赢"？**
因为任何纠纷的结果都取决于证据和具体情况，没人能提前保证。系统只给"法律怎么规定"和"可以怎么走"，
判断和决定留给你。

**Q：为什么有些问题它答不了？**
主要有两种情况：
1. **超出八个专项领域**——它会尽力检索，但标注"仅供参考"；
2. **依据在司法解释里**——例如"网贷利率超过多少就不受保护"，具体倍数由司法解释规定，
   而本系统的知识库只收法律、不含司法解释。这时它会明确告诉你"需另行核实"，而不是编一个数字。

**Q：我该不该把身份证号、银行卡号写进去？**
不需要，也建议不要。描述事实即可（例如"押金 2000 元"而不是提供转账账号）。系统的日志也做了打码处理。

**Q：它能帮我写起诉状吗？**
不会生成正式文书。但可以帮你把**案情要点、请求事项和证据清单**整理成提纲——拿这份提纲去找律师或
自己写，都会快很多。

## 七、最后

遇到具体纠纷、金额较大或情况复杂，**请咨询专业律师**；学校通常也有法律援助或法律咨询窗口。

> 以上内容仅供参考，不构成法律意见，具体问题建议咨询专业律师。
