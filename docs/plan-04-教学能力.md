## 1. 目标

让产品从"回答问题"变成"教会人"。四项能力：**知识点体系导航、概念辨析、案例教学、学习路径推荐**。

---

## 2. 能力一：知识点体系导航（FR-8）

### 2.1 形态

```
民法
├── 总则
│   ├── 民事主体
│   │   ├── 自然人的民事权利能力     [掌握度 82%]
│   │   └── 宣告失踪与宣告死亡       [掌握度 41%] ← 薄弱
│   └── 民事法律行为
│       └── 意思表示
└── 合同编
    └── 合同的效力
        ├── 有效要件
        └── 无效与可撤销              [未学]
```

### 2.2 交互

- 点击知识点 → 展示定义 + 关联法条原文 + 易混点 + 同类题入口；
- 每个知识点显示**掌握度徽标**（未学 / 薄弱 / 一般 / 扎实）；
- 支持"从法条反查知识点"（给定《民法典》第143条 → 关联知识点）。

### 2.3 硬要求

每个知识点必须挂靠至少 1 条法条（plan-02 §4.2），**挂靠不上的一律不展示**——防止凭空造概念。

## 3. 能力二：概念辨析（FR-2）

### 3.1 数据基础

`confusable_with` 字段（plan-02 §4.1）。无标注的易混对由知识点检索补充（同章节 + 高相似度）。

### 3.2 输出结构（固定）

| 维度 | 概念 A | 概念 B |
|---|---|---|
| 定义 |
| 法律依据 | 《X》第 N 条 | 《Y》第 M 条 |
| 构成要件 |
| 法律后果 |
| 典型例子 |

**区分标准**：一句话给出最省力的辨别钥匙（如"看是否有约定：定金是担保，订金是预付款"）。

### 3.3 硬要求

- 法条依据必须回库核验（走证据 Agent）；
- 无易混数据的组合，明确说"系统未收录该组的对照数据"，**不得臆造区别**。

## 4. 能力三：案例教学（FR-3）

### 4.1 分层引导协议（借鉴阶层论先例，见 PRD §4）

```
第 1 步：呈现案情（含时间、主体、行为、结果、2–3 个争议焦点）
第 2 步：提示思考维度，不给答案 —— 例如刑法按
        构成要件该当性 → 违法性 → 有责性 三层，每层给 1 句引导
第 3 步：用户提交自己的分析
第 4 步：批改，四个维度逐项判定
        事实认定是否遗漏 / 法律适用是否正确 / 推理链是否完整 / 法言法语是否规范
第 5 步：给参考答案 + 关联知识点 + 同类练习推荐
```

### 4.2 两条铁律

1. **先提示后答案**：用户未作答前，任何环节不得吐露结论；
2. **案情来源可溯**：优先用题库/官方案例改编；若用模板生成，必须标注"教学示例，非真实案例"。

### 4.3 难度渐进

| 档位 | 争议焦点数 | 干扰信息 | 适用 |
|---|---|---|---|
| 入门 | 1 | 无 | 初学 |
| 标准 | 2 | 少量 | 常规练习 |
| 进阶 | 3 | 有 | 法考冲刺 |

## 5. 能力四：学习路径推荐（FR-7）

### 5.1 算法（确定性，可复现）

```
输入：学习者掌握度向量 M、目标 T（部门法或考试）
1. 展开 T 对应的知识点图，得到候选集 C
2. 过滤：M(kp) ≥ 掌握阈值（默认 90%）的知识点剔除   ← 借鉴"掌握率>90%不显示"
3. 排序：按 (前置未满足 → 优先) then (掌握度升序) then (难度升序)
4. 输出：Top N 序列，每项含 知识点 + 理由 + 预计练习量
```

### 5.2 硬要求

- **可复现**：同输入恒定输出（无随机）；
- **可解释**：每条推荐必须给出理由（"前置知识点未掌握"/"正确率仅 41%"）；
- **前置依赖显式**：知识点 schema 需增加 `prerequisites` 字段。

### 5.3 输出示例

```
你的下一步（合同效力方向）
1. 无效与可撤销   理由：正确率 33%，且是"合同的履行"的前置   建议：8 题
2. 意思表示       理由：尚未学习，为上面知识点的前置         建议：5 题
```

## 7. 验收标准

| 项 | 标准 | 可验证 |
|---|---|---|
| A1 | 概念辨析必带法条依据且回库核验 | 失败数 = 0 |
| A2 | 案例教学不提前泄底 | 用例断言：作答前输出不含结论 |
| A3 | 路径推荐可复现且可解释 | 同输入 100% 一致；每条带理由 |
| A4 | 已掌握知识点不出现在路径 | 违反数 = 0 |
| A5 | 无反数据组合不臆造 | 无数据时输出"未收录"而非编造 |
| A6 | 教学层用例通过 | ≥ 95% |
