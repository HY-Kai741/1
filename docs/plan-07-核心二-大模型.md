# plan-07 · 核心二：大模型（LLM）

| 项 | 值 |
|---|---|
| 对应 PRD | §8.2 大模型 |
| 阶段 | Phase 5 |
| 优先级 | P0 |
| 依赖 | plan-03 |
| 规模档 | 中 |

---

## 1. 目标

明确模型能做什么、不能做什么，并把这条界线**写进代码**，而不是写在文档里靠自觉。

**一句话立场：模型是措辞层，不是事实层。默认关闭。**

---

## 2. 能力矩阵（唯一权威）

| 用途 | 用模型 | 约束 |
|---|---|---|
| 法条检索 | ❌ | 事实性硬约束 |
| 法条原文输出 | ❌ | 必须逐字来自库 |
| 客观题判题 | ❌ | 标准答案确定 |
| 掌握度计算 | ❌ | 必须可复现 |
| 学习路径排序 | ❌ | 必须可复现 |
| 错题归因 | ❌ | 规则判定 |
| 答疑措辞润色 | ✅ | 只改措辞，不改事实；失败静默回退 |
| 概念辨析文本组织 | ✅ | 内容来自知识点库，模型只做组织 |
| 主观题逻辑校验（第三层） | ⚠️ | 仅作辅助信号，**不得单独决定分数** |
| 案例事实生成 | ⚠️ | 模板驱动；**禁止生成法条引用**；必须标注"教学示例" |
| 出题 | ⚠️ | 仅生成变体候选，**必须过规则校验才入库** |

---

## 3. 技术形态

### 3.1 网关

```
业务代码 ──► llm_gateway ──► 厂商 A / B / C
                 │
                 ├─ 开关（默认关闭）
                 ├─ 超时 + 重试（1 次）
                 ├─ 熔断（连续失败 N 次即停用）
                 ├─ 提示词版本化
                 └─ 用量与成本记录
```

### 3.2 配置

| 变量 | 默认 | 说明 |
|---|---|---|
| `LLM_ENABLED` | `false` | 总开关 |
| `LLM_API_KEY` | 空 | 密钥 |
| `LLM_BASE_URL` | 空 | OpenAI 兼容端点 |
| `LLM_MODEL` | 空 | 模型名 |
| `LLM_MAX_TOKENS` | 512 | 上限 |
| `LLM_TIMEOUT_S` | 12 | 超时 |

**沿用前身设计：任一变量缺失 → 网关禁用 → 全链路走模板文案。** [实证] 当前线上 `llm.enabled = false`。

---

## 4. 提示词铁律（所有调用共用）

```text
你是法律教学内容的编辑。你会看到已经确定好的事实（法条原文、知识点、
采分点）。你的任务是让表达更自然易懂。

硬性要求：
1) 不得改变任何事实的含义、条件与后果；
2) 不得新增或修改任何法律名称、条款编号、金额、期限；
3) 不得给出"一定能赢""肯定违法"之类的绝对判断；
4) 不得新增未经提供的事实；
5) 只输出改写后的内容本身，不要任何前后缀。
```

**提示词必须版本化**（`prompts/v1/...`），且变更需要跑回归。

---

## 5. 输出后置校验（不可省略）

模型返回后，**必须**经过：

| 校验 | 动作 |
|---|---|
| 事实一致性 | 检查模型输出是否出现未提供的法条编号 → 有则丢弃 |
| 禁用词 | 绝对判断词命中 → 丢弃 |
| 长度 | 超限 → 丢弃 |
| 引用核验 | 若含引用，走 `evidence.check` → 不通过则丢弃 |

**校验失败一律回退到确定性文案。** 沉默回退，但记 warn 日志。

---

## 6. 降级与成本

| 场景 | 行为 |
|---|---|
| 无密钥 | 全程不使用模型（**默认路径**） |
| 超时 / 非 200 | 单次重试，仍失败 → 回退模板 |
| 连续失败 ≥ 3 次 | 熔断 5 分钟，期间全部走模板 |
| 成本超预算 | 自动降级为"仅答疑润色" |

## 8. 验收标准

| 项 | 标准 | 可验证 |
|---|---|---|
| A1 | 默认关闭时不调用任何模型 | 出网请求数 = 0 |
| A2 | 开启后事实零漂移 | 开启/关闭两态的法条引用集合完全一致 |
| A3 | 模型不产出未被提供的法条编号 | 违规数 = 0 |
| A4 | 熔断生效 | 失败 N 次后不再调用 |
| A5 | 提示词版本可追溯 | 每次调用记录 prompt 版本 |

**A2 是本计划最关键的断言**：它保证"用了模型"不会破坏"零编造法条"这条底线。

---

## 9. 依赖与风险

| 风险 | 等级 | 应对 |
|---|---|---|
| 模型幻觉污染教学内容 | 高 | 默认关闭 + 后置校验 + 事实一致性断言（A2） |
| 引入模型后成本失控 | 中 | 预算上限 + 自动降级 |
| 提示词漂移导致行为变化 | 中 | 版本化 + 变更必跑回归 |
| 供应商锁定 | 低 | 只依赖 OpenAI 兼容协议，端点可换 |
