## 1. 目标

把产品领域从「法律服务」**冻结**为「法律教育」，并把由此产生的边界写成代码可执行的规则，而不是文档里的一句话。

一句话验收：**任何一条越界请求都能被系统拦下并给出教学替代方向。**

---

## 2. 范围

### 2.1 做

1. 依 `目标.md` 五条标准出具领域判定结论（已在 PRD §1.2 完成）；
2. 定义"教学可做 / 服务不可做"的**请求分类表**；
3. 把不可做项转成护栏规则（进入 plan-08）；
4. 更新对外文案与免责声明（教学用途版）；
5. 更新 README / 使用说明的定位表述。

### 2.2 不做

- 不做资质申请、不做法律实体变更（超范围）；
- 不改动前身已有的 8 阶段流水线结构（只改文案与护栏）。

### 2.3 场景范围（2026-10-14 修订：**不再局限于 5 个场景**）

前身（法律问答 Agent）只覆盖 5 个场景：租房 / 兼职 / 消费 / 知识产权 / 借贷。
本次修订解除该限制，法律数据改以 `数据网址.md` 所列官方源为准（`flk.npc.gov.cn` 等），
场景按「学生真实高频 × 法条可支撑」两条标准扩展。

**扩展候选（依据 10.3 万条已抓取语料的引用统计，详见 `docs/DATA-BANKS.md` §6）：**

| 优先级 | 建议场景 | 主要法律依据 | 语料支撑 | 状态 |
|---|---|---|---|---|
| P1 | 网络与个人信息（含网络诈骗） | 个人信息保护法、反电信网络诈骗法、网络安全法 | 反电诈法 953 次 | **已落地**（8 条法条 / 10 个知识点 / 4 题） |
| P1 | 婚姻家庭与恋爱财产纠纷 | 民法典婚姻家庭编 | 强 | **已落地**（8 条法条 / 9 个知识点 / 4 题） |
| P1 | 人身损害与交通事故 | 民法典侵权责任编 | 强 | **已落地**（9 条法条 / 10 个知识点 / 4 题） |
| P2 | 治安与刑事风险（打架、帮信、盗窃） | 治安管理处罚法、刑法 | 强 | 待评估 |
| P2 | 就业与实习劳动权益 | 劳动合同法、就业促进法、社会保险法 | 2,238 / 1,325 / 1,873 | 待评估 |
| P2 | 网络言论与名誉权 | 民法典人格权编 | 中 | 待评估 |
| P3 | 校园消费金融与征信 | 商业银行法、征信业管理条例 | 中 | 待评估 |

> **P1 落地实证（2026-10-10）**：三个 P1 场景已全部上线，`scene_map.json` 由 5 场景 / 35 条扩至
> **8 场景 / 60 条映射法条**（59 条互异）。构建期核验 `scripts/verify_maps.py` **60 / 60 通过**；
> 知识点 39 → **68 个**（覆盖 59 条互异法条）；题库 8 场景共 **27 题**，门禁 0 问题；
> 评测集 23 → **29 条全绿**；回答隔离性回归覆盖 8 个领域全部通过。三场景均已在

> **前置条件**：新增场景必须先核验 `data/laws.db` 是否收录对应法律；
> 未收录的须先补库（走 MIT 许可的镜像源），再建知识点与题库。
> 未完成法条核验的场景**不得上线**——这是 `需求和要求.md`「禁止编造法条」的延伸要求。

**场景扩展仍受 §2.2 与产品定位约束**：新增场景同样是「普法教学」，不得因此滑向个案法律意见。

## 3. 请求分类表（本计划核心产出）

| 请求类型 | 示例 | 判定 | 处理 |
|---|---|---|---|
| 概念学习 | "什么是善意取得" | ✅ 教学 | 正常讲解 + 法条溯源 |
| 概念辨析 | "定金和订金区别" | ✅ 教学 | 对比表 + 区分标准 |
| 案例练习 | "分析这个案例构成什么罪" | ✅ 教学 | 分层引导 + 批改 |
| 刷题 | "给我出几道合同法的题" | ✅ 教学 | 出题 + 判题 + 解析 |
| 学情咨询 | "我哪部分薄弱" | ✅ 教学 | 错题诊断 + 掌握度 |
| 知识普及 | "劳动法都规定了啥" | ✅ 教学 | 知识框架 + 路径 |
| **个案咨询** | "我这个押金还能要回来吗" | ⚠️ 转教学 | 不判定个案，改为讲解相关知识点与法律规定 |
| **文书生成** | "帮我写起诉状" | ❌ 拒答 | 只整理案情要点与知识点清单 |
| **诉讼策略** | "我这个案子怎么打" | ❌ 拒答 | 说明属于法律服务范畴，超出教学范围 |
| **合同审查** | "帮我看看这份合同有没有坑" | ❌ 拒答 | 转为讲解合同相关知识点 |
| **伪造证据 / 逃避债务 / 索取隐私** | — | ❌ 拒答 | 沿用前身红线，给合规替代方向 |
| **绝对判断请求** | "他肯定违法对吧" | ⚠️ 改写 | 不给结论，讲判断要件 |

> 关键设计：**"个案咨询"不硬拒，而是降级为教学设计**。用户问"我的押金能不能退"，系统答"押金能否退还在法律上取决于 X/Y/Z 三个要件，下面逐个讲，并给一道同类练习题"——既守边界，又不赶走用户。

## 5. 教学用途声明（定稿）

```
以上内容仅用于法律知识学习与教学参考，不构成法律意见，也不针对你的具体
个案作出判断。如你正在处理真实纠纷，请携带材料咨询执业律师或当地法律
援助机构。AI 给出的评分与掌握度仅供学习进度参考，不作为课程成绩或能力
评价的依据。
```

与原版差异：新增第三句"个案"限定 + 第四句"AI 评分不作为评价依据"。
