## 1. 目标

把"刷题"做成**有反馈的闭环**：出题 → 作答 → 判题 → 归因 → 更新掌握度 → 影响下一步路径。

---

## 2. 能力一：出题（Quiz Generation）

### 2.1 三种出题模式

| 模式 | 来源 | 是否用模型 |
|---|---|---|
| 题库抽题 | 题库（plan-02） | ❌ |
| 知识点组卷 | 按知识点 + 难度筛选 | ❌ |
| 题目变体生成 | 由模板改造题库题（换数字/换主体） | ⚠️ 受限（模板驱动） |

### 2.2 组卷策略（确定性）

```
1. 输入：知识点集合 K、题量 N、难度分布 D
2. 权重：w(kp) = 1 - M(kp)     ← 掌握度越低，出题权重越高
3. 抽题：按 w 加权，同题不重复；已答过的降权
4. 校验：覆盖知识点数 ≥ min(N, |K|)；难度分布符合 D
```

**借鉴智能组卷实践（PRD §4）：按薄弱点动态提高出题权重。** 但**必须可解释**——组卷结果需附理由（"本题组针对你的 3 个薄弱知识点"）。

### 2.3 硬要求

- 每道题必须挂靠 ≥ 1 个知识点；
- 题目的 `citations` 必须回库核验；
- 变体生成的题目必须经**规则校验**（题干合法、答案唯一、选项互斥）后才入库，**不得由模型直接产出终态题目**。

## 3. 能力二：判题（Grading）

### 3.1 客观题（确定性，不用模型）

| 题型 | 判定 | 输出 |
|---|---|---|
| 单选 | 精确匹配 | 对/错 + 解析 |
| 多选 | 集合相等 | 对/错 + 漏选项/错选项标注 |
| 不定项 | 集合相等 | 同上 |
| 判断 | 布尔匹配 | 对/错 |

**准确率目标 100%**——这是可精确验证的。

### 3.2 主观题（三层初评 + 双轨）

```
第一层  逐句拆解：按 法律要件 / 事实认定 / 法条适用 切分考生答案
第二层  采分点匹配：与标准答案的得分要素比对 → 命中 / 部分命中 / 未命中
第三层  逻辑校验：检查论证链是否断裂、有无自相矛盾
输出    得分明细 + 采分点命中表 + 薄弱维度 + 改进方向
```

**强制的双轨设计（借鉴实践先例）：**
1. 结果标题必须是 **「AI 初评」**，不得写成"得分"；
2. 必须给出**具体理由**（哪条采分点没踩中），纯分数无效；
3. 必须提示**可提交人工复核**；
4. **不得给出绝对结论**（沿用 C4：禁止"一定不会得分"这类表述）。

### 3.3 主观题能力边界（必须如实告知）

对深层法律论证、价值判断的合理性，机器判断力不及专业教师。系统必须显式声明这一边界，而不是假装能评。

## 4. 能力三：错题诊断（Diagnosis）

### 4.1 归因层级

```
题目 → 知识点 → 考点簇 → 薄弱主题
```

**关键：输出"错在哪一类"，而不是"错了哪几道"。**

### 4.2 归因类型

| 类型 | 判定依据 | 建议 |
|---|---|---|
| 概念不清 | 同知识点反复错 | 回看知识点 + 概念辨析 |
| 要件遗漏 | 多选漏项模式 | 要件清单训练 |
| 审题失误 | 正确率高但该题错、耗时异常短 | 审题提醒 |
| 知识盲区 | 该知识点首次接触即错 | 系统学习该知识点 |
| 混淆 | 与易混知识点成对出错 | 触发概念辨析 |

### 4.3 输出示例

```
诊断：民法 · 合同的效力
- 反复出错的知识点：无效与可撤销（3 题错 3）
- 归因：概念混淆 —— 你与「效力待定」成对出错
- 建议：先看概念辨析（无效 vs 可撤销 vs 效力待定），再练 6 题
```

## 5. 能力四：掌握度评估（Mastery）

### 5.1 计算模型（确定性，可复现）

```
M(kp) = 正确率 × 难度系数 × 时效衰减
  正确率 = 加权正确题数 / 加权总题数     （越近的作答权重越高）
  难度系数 = 归一化的题目平均难度
  时效衰减 = exp(-Δt / τ)，τ 为遗忘常数
```

### 5.2 分档

| 档 | 区间 | 徽标 |
|---|---|---|
| 未学 | 无作答记录 | 未学 |
| 薄弱 | < 50% | 薄弱 |
| 一般 | 50%–80% | 一般 |
| 扎实 | ≥ 80% | 扎实 |
| 已掌握 | ≥ 90% | 已掌握（路径中剔除） |

### 5.3 硬要求

- **可复现**：同输入恒定输出（不得引入随机）；
- **单调性**：同难度下答对 → 掌握度不下降；答错 → 不上升（可作为单测断言）；
- **可解释**：能显示"由哪几道题算出来的"；
- **不做无依据推断**：无作答记录 → 显示"未学"，绝不猜。

## 7. 验收标准

| 项 | 标准 | 可验证 |
|---|---|---|
| A1 | 客观题判题与标准答案 100% 一致 | 全部题库回归通过 |
| A2 | 主观题初评给出可解释理由 | 无理由的评分条数 = 0 |
| A3 | 主观题输出必带「AI 初评」标注 | 字符串断言 100% |
| A4 | 掌握度可复现 + 单调性正确 | 单测 100% |
| A5 | 错题归因到知识点层 | 无归因的错题数 = 0 |
| A6 | 组卷可解释 | 无理由的题组数 = 0 |
| A7 | 掌握度 < 阈值时路径不剔除 | 违反数 = 0（与 plan-04 联测） |
