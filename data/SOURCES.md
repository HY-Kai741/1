# 数据来源与边界说明（SOURCES）

本系统的一切法条内容都来自**本地知识库**，不联网、不调用任何大模型生成法条文本。
本文件说明数据是什么、从哪来、覆盖到哪里、有哪些已知局限。

---

## 一、知识库来源

| 项 | 内容 |
|---|---|
| 项目 | **china-law-mcp**（中国法律条文检索 + 引用核验） |
| 仓库 | `https://github.com/thu-lawyer/china-law-mcp` |
| 版本 | v0.1.1 |
| 许可 | **MIT**（副本见项目根目录 `LICENSE-china-law-mcp.txt`） |
| 数据文件 | `data/laws.db`（SQLite；上游原样 **14.6 MB**，本项目补索引后 **15.8 MB**） |
| 是否需要 API key | **不需要**。完全离线 |
| 本系统用法 | vendor 其 `database.py` / `retrieval.py` 到 `legal_agent/lawkb/`，**未改动检索逻辑**；仅把默认库路径指向本项目 `data/laws.db` |
| 本地改动 | 仅**新增一条查询索引** `idx_articles_name_no(law_name, article_no_arabic)`（见 `scripts/optimize_db.py`）：上游只建了 `law_id` 索引，而本系统按「法律全名 + 条号」直查，原为 26,196 行全表扫描（约 34 ms/次）。**条文内容一字未改**，原文逐字一致性不受影响 |

> 备选方案 `legal-kb-builder` 未采用：它依赖 PDF 解析后端（MinerU / TextIn / PaddleOCR 等）
> 与多套流水线，接入成本高，且不能解决本任务真正的难点（法条精准定位与防编造核验）。

## 三、三条硬边界（必须如实告知用户）

### 1. 不含司法解释

库内**只有宪法、法律、立法解释**，**不含司法解释、行政法规、地方性法规**。

实际影响举例：**网络借贷的"利率司法保护上限"**（如"一年期 LPR 的 4 倍"）依据的是
《最高人民法院关于审理民间借贷案件适用法律若干问题的规定》，**不在本库内**。
因此系统只能引用《民法典》第六百八十条"禁止高利放贷"，并在"数据说明"里提示用户另行核实，
**绝不编造具体倍数**。

类似地，消费者"退一赔三/退一赔十"的具体适用、劳动争议的举证规则等，涉及司法解释的部分
系统都只做路径提示，不做确定结论。

### 2. 语料存在同名同条号的重复条目

审计脚本 `python scripts/audit_kb.py` 的结果：

```
现行有效条文总数        : 23995
同名不同 law_id 的法律  : 0
「法律名+条号」文本冲突 : 42       ← 同名同条号但文本不同
专项映射法条            : 60 条（8 个领域，59 条互异）
其中落在冲突集内的       : 0 条（不受影响）
```

- 42 处冲突主要集中在**《刑法》**（修正案"第 X 条之一/之二"被归一为同一阿拉伯条号）。
- 处置：
  1. 映射命中的法条一律按 **主键 `id`** 取值，并把 `article_id` 随结果返回，保证可溯源；
  2. 八领域 60 条法条构建期逐条核验，**0 条落在冲突集内**；
  3. 兜底检索路径的结果一律标注"仅供参考"。

### 3. 时效状态为库内推定

条文时效字段部分为库内推定（上游 `status_basis` 字段）。系统只使用
`现行有效` 与 `已被修改` 两种状态的条文；修法频繁的领域请以官方公布文本为准。

## 四、防编造的工程保障

| 机制 | 位置 |
|---|---|
| 法条原文只从 `data/laws.db` 取，任何环节不生成法条文本 | `legal_agent/statutes.py` |
| 场景→法条映射在构建期逐条核验存在性与原文关键词 | `scripts/verify_maps.py` |
| 运行期再做一次防御性核验，不通过即丢弃并记 warn | `legal_agent/statutes.py::_passes_keyword_guard` |
| 评测断言：输出中每条引用回库核验 + 原文逐字比对 | `tests/run_eval.py`（G1/G2） |
| 保留上游"凡引用先 verify"的铁律 | `legal_agent/lawkb/database.py::find_article` |

## 五、复现命令

```bash
# 1) 拉取知识库源码与法条库（构建期一次性）
git clone --depth 1 https://github.com/thu-lawyer/china-law-mcp.git data/external/china-law-mcp
cp data/external/china-law-mcp/data/laws.db data/laws.db

# 2) 补查询索引（幂等；只加索引，不改条文）
python scripts/optimize_db.py

# 3) 核验八领域映射（60 条）
python scripts/verify_maps.py

# 4) 审计语料一致性（重复条目 / 条号文本冲突）
python scripts/audit_kb.py

# 5) 全量回归
python tests/run_eval.py && python tests/smoke_http.py && python tests/test_variation.py
```

> 运行时**不需要** `data/external/`（原始克隆仓库），部署时已排除；运行时只需要 `data/laws.db`。
